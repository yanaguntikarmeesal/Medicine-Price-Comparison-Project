## 💊 Medicine Price Comparison System — Project Summary

The **Medicine Price Comparison System** is a Python-based web application developed using **Streamlit** that helps users compare medicine prices available from different online shopping sources. The application uses **SerpApi and Google Shopping** to retrieve real-time product information based on the medicine name entered by the user.

The system extracts important details such as **medicine name, company/store, price, and purchase link**. It uses **Regular Expressions (Regex)** to clean and convert price values into numerical formats. **Pandas** is used to organize and analyze the collected data, while **Matplotlib** and Streamlit are used to visualize price comparisons through **bar charts and pie charts**.

The application automatically identifies the **lowest-priced option** and provides a direct purchase link when available. Users can also view all retrieved price details in a structured data table.

### 🔧 Technologies Used

* Python
* Streamlit
* SerpApi / Google Shopping API
* Pandas
* Matplotlib
* Regular Expressions

### ⭐ Key Features

* 🔎 Search medicine by name
* 🏪 Compare prices from multiple sources
* 💰 Identify the lowest price
* 🛒 Provide purchase links
* 📊 Generate price comparison charts
* 🥧 Display price distribution
* 📋 Show structured price details
* ⚠️ Handle missing results and API errors
